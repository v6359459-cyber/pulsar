# PULSAR 1.3.1

## Исправлено

- **Микрофон:** больше не пишет «whisper build not found», голосовой движок снова скачивается.
- **Вкладка API:** осталось только поле ключа и имя API. Сервис определяется сам, ключ проверяется сразу после вставки, потом выбираешь модели.
- **Режим «вместе»:** отвечают модель с ПК и все подключённые API, два круга спора, победитель выбирается голосованием.
- Кнопки микрофона и скрепки выровнены на одной линии.
- Убраны поля ключей поиска и Pexels.
- Больше анимаций в интерфейсе.

## Новое

### 👁 Модели видят картинки
- В разделе «Модели» у моделей, которые понимают изображения, есть пометка **«видит картинки»**: Gemma 4 E4B, Gemma 4 12B, Gemma 4 26B A4B, Qwen3.5 9B.
- Фото или скриншот можно прикрепить в чат скрепкой или перетащить мышкой. Например: «сделай сайт как на этом скрине» или «что на фото?».
- Вверху чата видно, видит ли выбранная модель картинки.
- Модели без зрения фото не принимают: PULSAR напишет об этом. Другие файлы (txt, pdf, docx, код, csv) прикреплять можно в любую модель.
- Зрение локальной модели докачивается и включается само при первой картинке.
- Через API картинки видят GPT-4o / 4.1 / 5, Claude, Gemini, Grok, Qwen-VL, Pixtral и другие.

### 📷 Настоящие фото на сайтах
- Когда агент делает сайт, PULSAR спрашивает, нужны ли настоящие фото.
- Если да, подбирает их под каждый блок сайта: бесплатно с Openverse, а если указан бесплатный ключ Pexels (вкладка API), то с Pexels.
- Фото сохраняются в папку сайта `img/`, поэтому сайт работает без интернета, и его можно отдать клиенту.
- Внизу сайта появляется подпись с авторами фото.

### 🎙 Голос
- Кнопка микрофона в чате: говоришь, и текст появляется в поле ввода.
- Распознавание работает прямо на ПК: Whisper small, около 470 МБ, скачивается один раз при первом нажатии.
- 🔊 у каждого ответа: прочитать вслух голосом Windows.
- В «Оптимизации» можно включить «Озвучивать ответы».

### 🔒 Ключи API зашифрованы
- Ключи API, поиска и Pexels хранятся зашифрованными средствами Windows.
- Старые ключи шифруются сами при первом запуске.

### ↩️ Откат при неудачном обновлении
- Если новая версия два раза подряд не запустилась, PULSAR сам ставит последнюю рабочую версию.
- На сломанную версию он больше не обновляется, пока не выйдет следующая.
