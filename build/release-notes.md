# PULSAR 2.1

## 🖼 Генерация фото
Новый раздел «Генерация фото». Работает как обычные модели: выбираешь, скачиваешь, запускаешь. Восемь моделей в трёх группах — от **SD Turbo** (1 ГБ, рисует за секунды даже без видеокарты) до **Qwen Image 2.1** (8,5 ГБ, лучше всех рисует надписи, в том числе по-русски). У каждой карточки видно, потянет ли её твой ПК. Движок stable-diffusion.cpp докачивается сам перед первой картинкой. Готовые картинки лежат в галерее внизу раздела и в своей папке.

## 🧠 Модели
Каталог вырос с 18 до 28. Новая группа **«Для слабых ПК»** — Qwen3 1.7B, Gemma 3 1B, Qwen3 4B: работают без видеокарты на 8 ГБ памяти. Сильные кодеры **Qwen3 Coder 30B A3B** и **Devstral Small 2 24B**. Ещё три зрячих модели — **Qwen3 VL 4B / 8B** и **Qwen 2.5 VL 7B** (теперь зрячих семь). Тяжёлые **GLM 4.5 Air** и **gpt-oss 120B** для машин с большой памятью.

## 🎨 Дизайн
Стилей сайтов стало восемь: к минимализму Apple, неону, стеклу и корпоративному добавились **Брутализм** (жирные рамки, резкие тени), **Терминал** (моношрифт, зелёный по чёрному, мигающая каретка), **Журнал** (крупные заголовки, колонки, строгая сетка) и **Градиенты** (плавные переходы, размытые пятна, стеклянные карточки).

## Исправлено

### 🎯 «Калькулятор напиши» больше не уходит в разговор
Правило выбора агента требовало глагол строго перед существительным, поэтому «напиши калькулятор» работало, а «калькулятор напиши» — нет, и задача попадала в HELLO PULSAR. Теперь порядок слов не важен, а список вещей шире: таймер, тудушка, парсер, конвертер, викторина, бот.

### 🤐 HELLO PULSAR больше не спихивает задачи
В его инструкции было прямо написано предлагать включить «Авто» — он и предлагал, даже когда «Авто» уже включено. Убрано: задачу уже направили ему, и он отвечает сам.

### 🧹 Размышления модели не лезут в ответ
Некоторые модели печатают ход мыслей обычным текстом, без тегов: «The user is asking me to write a calculator. According to my instructions…». Теперь такое вступление срезается, а ответ остаётся. Английский ответ по делу при этом не трогается.

### 🔑 API больше не врёт про сервис
Ключ без узнаваемого префикса перебирался по списку сервисов, и засчитывался первый, чей список моделей ответил. SambaNova отдаёт список вообще без проверки ключа — поэтому любой чужой ключ подписывался как «от SambaNova». Теперь при переборе ключ проверяется настоящим запросом. А поле «Имя» убрано совсем: API подписывается названием модели, которое никогда не догадка.

### 🎨 Цвета вернулись
Тёмная тема снова чёрно-белая, как была. Светлая осталась на нормальной палитре, а не на инверсии цветов.

### ⚪ Три кружка вместо текста
Пока модель работает, теперь пульсируют три точки, а название этапа стоит рядом мелким.
