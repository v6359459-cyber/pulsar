# PULSAR 1.2.0

## Новое в 1.2.0

### Раздел «Дизайн»
- 25 готовых блоков в стиле shadcn/ui: шапка, первый экран, карточки, меню и прайс, тарифы, отзывы, команда, галерея, товары, вопросы, этапы, цифры, контакты с формой, подвал, дашборд с таблицей и другие.
- 4 стиля: минимализм Apple (по умолчанию), тёмный tech / неон, стекло и мягкие цвета, строгий корпоративный.
- Модель собирает страницу только из блоков и не пишет CSS. Стили и анимации PULSAR добавляет сам: появление при прокрутке, заголовок по словам, счётчики цифр, размытая шапка, меню для телефона.
- 8 примеров «запрос → сайт»: модели подкладываются самые подходящие к запросу.
- Предпросмотр каждого стиля во встроенном браузере.
- Тумблер «Режим дизайна»: если выключить, модель оформляет сайт сама.
- Сайты открываются без интернета.

## Новое в 1.1.0

### API
- Вкладка API: вставляешь ключ и жмёшь «Проверить». PULSAR сам определяет сервис: OpenRouter, Groq, Gemini, Claude, OpenAI, DeepSeek, xAI, Mistral, Kimi, NVIDIA, Hugging Face, Cerebras и другие.
- Для своего сервера есть поле с адресом API.
- Список моделей с поиском, бесплатные показаны сверху.
- Каждая модель проверяется настоящим запросом. Если она ответила, появляется надпись «API подключён».
- Можно подключить много ключей и моделей и удалить любую.
- Понятные ошибки: неверный ключ, нет денег на счету, кончился лимит, нет доступа, нет связи.

### Выбор модели в чате
- **ПК** — локальная модель.
- **API** — облачная модель.
- **Вместе** — обе отвечают, проверяют ответы друг друга и выдают лучший итог. Для сайтов и программ каждая пишет свою версию, и остаётся та, где меньше ошибок.
- Все агенты работают и через API.

## Новое в 1.0.x
- **Агенты:** HELLO PULSAR, PULSAR CODE, FILE SUP (создаёт папки, перемещает и переименовывает файлы, ничего не удаляет) и PULSAR IN BROWSER (кликает, вводит текст и листает страницы, кнопки можно называть текстом).
- **Авто:** агент выбирается заново на каждое сообщение. Модель, которую выбрал ты, не меняется.
- **Только последний запрос:** агенты не повторяют прошлые задачи.
- **Защита от зацикливания:** PULSAR останавливает модель, если она начинает повторять одно и то же.
- **Ускорители для всех семейств моделей:**
  - сами скачиваются и подключаются;
  - вверху чата видно, работает ускорение или нет;
  - у каждого ускорителя свой тумблер;
  - учитывается память видеокарты.
- **Температура:** отдельные пороги для видеокарты и процессора, по умолчанию 75 °C.
- **Стоп:** при остановке пишет «Ответ прерван».
- **Чат и панель кода:**
  - чат можно листать во время ответа;
  - анимации этапов идут плавно;
  - в панели кода есть «Стоп», «Очистить» и запуск по Ctrl+Enter.
- **Интро и обновления:** интро при каждом запуске, обновления ставятся сами.

**Скачать:** `PULSAR-Setup-1.2.0.exe` ниже.

**Если ругается антивирус:** это ложное срабатывание. У установщика нет платной подписи, а приложение запускает локальный движок нейросетей. Подробности в README.
