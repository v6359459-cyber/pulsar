# PULSAR 2.2

Починка по следам 2.1. Две ошибки были моими — из-за них вчера ломалась работа.

## Исправлено

### 🛑 Ошибка «HTTP 500 · No user query found in messages»
Когда ответ обрывался по длине, PULSAR досылал запрос на продолжение, и в нём не было сообщения пользователя — только системное и начатый ответ. Шаблон llama.cpp такой запрос отклоняет. Теперь сообщение пользователя есть всегда, а на уровне отправки стоит страховка: запрос без него больше не уйдёт в принципе.

### ⏱ «Проверка и исправление» больше не тянется по пять минут
Три причины сразу. Падающие дозапросы повторялись до трёх раз. Проверка запускалась даже на 30-строчном калькуляторе, где ошибок нет. И перегрев — это и было «снижаю температуру».

Теперь: этап проверки **стартует только если машина действительно нашла ошибки**, иначе пропускается мгновенно с пометкой. Дозапрос повторяется один раз вместо трёх. На весь этап стоит потолок в полторы минуты.

### 🌡 Перегрев
Порог по умолчанию поднят с 75 до 85 °C: 75 — обычная рабочая температура под нагрузкой, поэтому паузы срабатывали постоянно. Остывание теперь считается по-другому: сработал порог — модель придерживается, пока карта не остынет **на 20 градусов ниже порога**, а не на 6, как было. Без этого она прыгала туда-сюда и работа проводила время в паузах.

### 🔑 Ключ API с ошибкой 403
В 2.1 я добавил проверку ключа настоящим запросом, чтобы SambaNova не присваивала себе чужие ключи. Но сервисы, которые на пробный запрос отвечают 403 (ограничение тарифа или модели), стали отбраковываться — рабочие ключи переставали подключаться. Теперь ключ отбраковывается **только по 401** (неверный ключ). 403, 404, 429 и сбой сети означают, что сервис ключ узнал.

### 🔤 Русские правила снова работают
В JavaScript `\b` не знает кириллицу, поэтому правила, заканчивавшиеся на него после русского слова, не срабатывали вообще. Нашёл и исправил все такие места; на каждое есть проверка в тестах.

### 🖼 Генерация картинок переехала
Отдельного раздела больше нет. Модели для картинок живут в «Моделях» своей группой: скачал → «Запустить» → пишешь в чате «нарисуй кота», и картинка появляется прямо в чате. Работает одна модель за раз — при запуске рисующей текстовая выгружается, чтобы освободить видеопамять.

Движок ищется рекурсивно и под всеми именами, которые встречались в релизах (`sd.exe`, `sd-cli.exe`, `stable-diffusion.exe`). Если не нашёлся — в ошибке теперь написано, какие файлы реально лежат в архиве. Если пин сборки протух, берётся свежая.

### 🔢 Мелочи, которые мозолили глаза
- «Докачать · 0.0 ГБ» — размеры меньше гигабайта показываются в мегабайтах. Размер обновляется сразу после отмены.
- Кнопки «Скачать» выровнены по низу карточки независимо от длины описания.
- Три пульсирующие точки теперь и в цепочке агентов, а не только в обычном ответе.
- Плашка сверху пишет число агентов по факту запуска: было «×2» всегда, теперь столько, сколько реально работает.
